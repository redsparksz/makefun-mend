mend is a command-line patch tool that applies AI-written edits — unified diffs, SEARCH/REPLACE blocks, V4A patches, and JSON tool-call edits — to a tree of text files, with three tiers of fuzzy line matching and all-or-nothing writes.

## Run it

```sh
node main.ts [options] [PATCH]
```
